# Planck's constant: photoelectric effect (virtual lab)

A browser-based, physics-driven, educational simulation of the compact photoelectric-effect arrangement used to determine Planck's constant h: mercury lamp, prism, potassium photocell, and a capacitor that charges up to the limit voltage U0.

**Live:** https://kairi99.github.io/photoelectric-sim/

Status: Phase 0 (scaffold). No physics yet.

## Development

```bash
npm install
npm run dev      # dev server
npm test         # Vitest
npm run build    # tsc + vite build into dist/
```
